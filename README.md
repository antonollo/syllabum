# Syllabum

> Plataforma para gestão, organização e acompanhamento de planos de estudo e ementas disciplinares para programadores.

---

## Sobre o Projeto:

O **Syllabum** é um sistema desenvolvido para não só centralizar e estruturar cronogramas de estudos, mas também proporcionar o acompanhamento do progresso acadêmico de forma clara e intuitiva, fazendo uso de tecnologias de Inteligência Artificial.

O repositório é organizado no formato de **mono-repositório**, contendo códigos tanto para o **Frontend**, como o **Backend** em subdiretórios dedicados.

---

## Arquitetura Geral:

```text
Syllabum/
├── frontend/          # Interface do usuário (Aplicação Web).
└── backend/           # API REST e serviços de regras de negócio/dados.
```

## Como executar o projeto localmente:

Para utilizar o Syllabum, certifique-se de ter instalado:

- Git;
- Node.js (para o Frontend);
- Python 3.10+ (para o Backend).

1. Clonando o repositório: 

```text 
git clone https://github.com/antonollo/syllabum.git
cd syllabum
```

2. Configurando e executando o Backend:

Para instruções mais detalhadas de configuração do banco de dados e ambiente virtual: **Veja o README em syllabum-backend**.

3. Configurando e executando o Frontend:

Para instruções mais detalhadas de configuração do frontend: **Veja o README em syllabum-frontend**.
